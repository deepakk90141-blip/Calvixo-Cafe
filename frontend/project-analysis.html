📌 Pattern: State parent me hoti hai, aur child tak props se jaati hai (prop drilling). Jaise Menu → Menu_Nevbar (props: food, setFood) aur Menu_items (props: food). Koi Context/Redux/Zustand nahi hai.

🔁 Data Flow / Logic Patterns

1. Filter pattern (Menu)

foodItems.filter(cat => food === "All" || cat.category === food) — Navbar button state food set karta hai, Menu_items uske hisaab se categories filter karta hai.

2. Switch/Render pattern (Card_route, AdminRoute)

switch(category) → alag component return. Isi tarah AdminRoute routes ke hisaab se PagesFirst/Second/Third/Fourth render karta hai.

3. Map-render pattern (sab pages)

Har array data (foods, features, Reviews, Partypackages, jobs, benefits...) ko .map() se loop karke cards render hote hain. Data sab AllDatas.jsx se aata hai.

4. Toggle pattern (wishlist)

setWishlist(prev => ({...prev, [id]: !prev[id]})) — heart icon on/off. Object-key based toggle.

5. Form submit pattern (LatestNews)

SubmitHandler(e) → e.preventDefault(), input reset, abhi bas console.log. Button click pe page reload nahi hota.

🧩 Logic Build karne ke liye (Tum kya add kar sakte ho)

  • Cart: "Add to Cart" buttons abhi dead hain — ek CartContext yaa state bana kar items add/remove karo.
  • Wishlist: Menu_items me state local hai — use global (Context) karke Homepage se bhi sync karo.
  • Auth: Register/Login forms me onSubmit + validation + localStorage/backend add karo.
  • Admin: AdminRoute/SidebarPages me pages linked hain — bas App.jsx me uncomment karke route do.
  • News subscribe: LatestNews me submit pe abhi sirf console.log — real validation + API baad me.
  • Booking/Apply: BookParty & ApplyForJob forms me submit handler + data save karo.
  • Search/Toast: Pehle se koi global notification ya loader system nahi hai — add kar sakte ho.

📋 Quick Summary

  • ✅ React 19 SPA with React Router 7 — 6 public pages (Home, Menu, Delivery, News, Party, Careers).
  • ✅ Single data hub: AllDatas.jsx — saara content yahi se aata hai.
  • ✅ State pattern: parent state + prop drilling. No Context/Redux yet.
  • ✅ Routing Navbar ke andar centralized (Navbar_Route.jsx).
  • ✅ Admin + Auth built par disabled (App.jsx me comment).
  • ✅ Forms & buttons abhi UI-only — data save/logic kisi ke paas nahi.
